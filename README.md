# منصة متجر لولو كب كيك | Lolo Cupcakes E-Commerce Platform

منصة تجارة إلكترونية متكاملة للحلويات الفاخرة (كيك، كب كيك، جاتوه، حلويات شرقية وغربية)، مصممة لدعم اللغة العربية كأولوية أولى (Arabic-first, RTL)، التوقيت المحلي للقاهرة (Africa/Cairo)، والعملة الرسمية بالجنيه المصري (EGP).

---

## 🏗️ المعمارية التقنية (Architecture)

تم بناء المشروع بنمط **Modular Monolith** صارم ومحكم وبدون تعقيدات البنية التحتية الزائدة (Zero Microservices, Zero Kafka, Zero Redis):
- **قاعدة البيانات (Database)**: PostgreSQL 16 Alpine مع إدارة ترحيل المخططات عبر **Flyway** (3 Migrations منشأة ومحققة).
- **الخلفية البرمجية (Backend)**: Java 21 + Spring Boot 3.3.5 (Spring Security, Spring Data JPA, Hibernate, Jakarta Validation, Actuator).
- **الواجهة الأمامية (Frontend)**: Next.js 14 (App Router) + TypeScript + Tailwind CSS (RTL, خط Cairo، ومكونات تفاعلية Lucide Icons).

---

## 🔒 القواعد التجارية والأمنية الصارمة (Invariants Enforced)

1. **الخلفية هي المرجع الوحيد للأسعار**: يتم احتساب كافة الأسعار، الخصومات، رسوم التوصيل، والإجماليات على السيرفر حصراً ولا يتم الوثوق بأي سعر مرسل من العميل.
2. **استقلالية حالة الطلب وحالة الدفع**: رفع إيصال التحويل البنكي/المحفظة لا يغير حالة الطلب إلى "مدفوع" آلياً؛ بل يتطلب مراجعة واعتماد يدوي من مسؤول المتجر (`STORE_MANAGER` أو `SUPER_ADMIN`).
3. **حجز السعة الزمنية الذري**: منع الحجز المزدوج للمواعيد (`TimeSlot`) تحت الضغط اللحظي باستخدام القفل التشاؤمي (`PESSIMISTIC_WRITE`).
4. **تتبع آمن للزوار (Guest Tracking)**: استخدام `tracking_token` عشوائي غير قابل للتخمين (UUID v4) لحماية خصوصية بيانات العميل وسجله.
5. **طلبات الكيك المخصص (Custom Cakes)**: لا تتحول إلى طلب نهائي إلا بعد تقديم عرض سعر فني محدد بمدة صلاحية واعتماده من العميل.
6. **حماية المرفقات الحساسة**: إيصالات السداد وتصميمات الكيك المخصصة تحفظ في مسارات خاصة محمية ولا تُعرض إلا بروابط مأمونة ومصادق عليها.

## 🚀 كيفية تشغيل المشروع محلياً (Quick Start)

### 1. تشغيل قاعدة البيانات (PostgreSQL via Docker)
```bash
docker compose up -d
# قاعدة البيانات تعمل على البورت 5433 خارجيًا (5432 داخلياً):
# jdbc:postgresql://localhost:5433/lolo_cupcakes
# المستخدم: lolo_admin / كلمة المرور: lolo_secret_2026
```

### 2. تشغيل الـ Backend (Spring Boot 3.3.5 / Java 21)
```bash
cd backend
export JAVA_HOME=$HOME/tools/jdk-21.0.5+11
export PATH=$JAVA_HOME/bin:$HOME/tools/apache-maven-3.9.9/bin:$PATH

# تشغيل الاختبارات الآلية (14 اختبار ناجح 100%):
mvn test

# تشغيل السيرفر المحلي (يعمل على البورت 8080):
mvn spring-boot:run
```

### 3. تشغيل الـ Frontend (Next.js 14)
```bash
cd frontend

# تثبيت الحزم (إن لم تكن مثبتة):
npm install

# بناء نسخة الإنتاج:
npm run build

# تشغيل السيرفر المحلي (يعمل على البورت 3000):
npm run dev
```

## 🔑 الحسابات والبيانات الافتراضية للتجربة (Seed Data)

- **حساب الإدارة المعتمد (Admin User)**:
  - البريد الإلكتروني: `admin@lolocupcakes.com`
  - الدور: `SUPER_ADMIN`
  - معرّف المسؤول: `a0000000-0000-0000-0000-000000000001`
- **فروع وتوصيل المتجر**:
  - الفرع: فرع القاهرة الجديد (الفرع الرئيسي)
  - مناطق التوصيل التجريبية: المعادي، التجمع الخامس، الزمالك، الدقي/المهندسين.
  - طرق الدفع: كاش عند الاستلام، وتحويل بنكي/محافظ إلكترونية (فودافون كاش / إنستاباي) مع رفع الإيصال.

## 📊 صفحات ومسارات المنصة

| المسار | الوصف |
| :--- | :--- |
| `/` | الصفحة الرئيسية للمتجر (Hero Banner، المميزات، التورت المخصصة، الفئات) |
| `/shop` | الكتالوج المباشر مع تصفية الفئات، البحث، ونافذة التخصيص للإضافات |
| `/checkout` | إتمام الطلب كزائر (توصيل/استلام، اختيار المواعيد، واحتساب الفاتورة) |
| `/orders/[orderNumber]?token=...` | صفحة تتبع الطلب ومسار التجهيز مع تعليمات الدفع ونموذج رفع الإيصال |
| `/track` | بوابة البحث السريع عن حالة الطلب برقم الطلب والرمز السري |
| `/custom-cake` | نموذج تقديم طلب تورتة خاصة بمواصفات وصور مرجعية |
| `/custom-cake/[ref]?token=...` | متابعة ومراجعة عروض الأسعار المقدمة من الشيف وقبولها/رفضها |
| `/admin` | لوحة تحكم الإدارة (المؤشرات، إدارة الطلبات، تدقيق التحويلات، تسعير التورت، والإعدادات) |
